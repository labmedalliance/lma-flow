Mit der Maus bearbeiten

Flussdiagramme bearbeitest du auch ohne Code. Jede Aktion schreibt den Code links sofort mit. Du kannst also jederzeit zwischen Maus und Text wechseln.

  • Knoten anlegen: Zieh eine Form aus der Leiste über der Vorschau in die Vorschau. Legst du sie auf einem Knoten ab, verbindet Flow beide mit einem Pfeil. Ein Klick auf eine Form hängt sie an den ausgewählten Knoten an.
  • Knoten ändern: Klick den Knoten an. Im Seitenfeld änderst du Text, Form und Farben. Enter übernimmt den Text.
  • Pfeil ziehen: Fahr mit der Maus über einen Knoten. Am rechten Rand erscheint ein blauer Punkt. Zieh ihn auf einen anderen Knoten. Auf dem Tablet nutzt du im Seitenfeld Pfeil zu … und tippst dann den Zielknoten an.
  • Pfeil ändern: Klick die Linie oder ihre Beschriftung an. Im Seitenfeld änderst du Beschriftung, Art und Farbe.
  • Löschen: Auswahl treffen und Entfernen drücken oder Löschen anklicken. Mit einem Knoten verschwinden auch seine Pfeile.
  • Rückgängig: ↶ und ↷ in der Leiste oder Cmd/Strg + Z, wenn der Cursor nicht im Code steht.
  • Richtung: Die Auswahl Richtung dreht das ganze Diagramm.

Die Anordnung berechnet Flow automatisch. Knoten lassen sich deshalb nicht frei verschieben. Bei sehr verschachteltem Code meldet Flow „bitte im Code ändern", statt zu raten. Mit der Maus geht das nur bei Flussdiagrammen und nur mit Recht Bearbeiten.

Grundlagen

Du beschreibst ein Diagramm als Text. Die Vorschau rechts im Editor zeichnet es sofort neu.

  • Die erste Zeile nennt den Diagrammtyp, zum Beispiel flowchart für ein Flussdiagramm.
  • Direkt dahinter steht die Richtung: TD von oben nach unten, LR von links nach rechts. BT und RL drehen die Richtung um.
  • Jede weitere Zeile beschreibt einen Knoten oder eine Verbindung. Einrücken ist erlaubt und macht den Code lesbarer.
  • Ein Knoten hat eine ID und einen Text: A[Probe eingegangen]. Die ID nutzt du für Verbindungen, angezeigt wird der Text.
flowchart LR
    A[Probe eingegangen] --> B[Zentrifugieren]
    B --> C[Messen]
    C --> D[Befund freigeben]

Einen Knoten, den du schon kennst, schreibst du später nur noch mit seiner ID. Mehrere Pfeile in einer Zeile sind erlaubt: A --> B --> C.

Pfeile

Die Zeichen zwischen zwei Knoten bestimmen die Art der Verbindung. Text auf dem Pfeil steht zwischen zwei senkrechten Strichen.

flowchart LR
    A[Pfeil] --> B[Linie ohne Spitze]
    B --- C[Gepunktet]
    C -.-> D[Dick]
    D ==> E[Mit Text]
    E -->|ja| F[Kreis-Ende]
    F --o G[Kreuz-Ende]
    G --x H[Beide Richtungen]
    H <--> I[Ende]

Mehr Bindestriche machen einen Pfeil länger, etwa A ---> B. Das hilft, wenn das Layout zu eng wird.

Farben

Einen Knoten färben: Schreib eine eigene Zeile mit style, der ID und den Farben. fill ist die Füllung, stroke der Rand, color die Schrift.

flowchart LR
    A[Probe in Ordnung] --> B[Probe hämolytisch]
    style A fill:#d1fae5,stroke:#059669,color:#064e3b
    style B fill:#fee2e2,stroke:#dc2626,stroke-width:3px

Mehrere Knoten gleich färben: Leg mit classDef eine Farbklasse an und häng sie mit ::: an die Knoten. So änderst du die Farbe später an einer Stelle.

flowchart TD
    A[Anforderung]:::station --> B[Abnahme]:::station
    B --> C[Analyse]:::labor --> D[Befund]:::labor
    classDef station fill:#dbeafe,stroke:#2563eb
    classDef labor fill:#fef3c7,stroke:#d97706

Pfeile färben: linkStyle zählt die Pfeile in der Reihenfolge, in der sie im Code stehen, ab 0.

flowchart LR
    A --> B --> C
    linkStyle 0 stroke:#dc2626,stroke-width:3px
    linkStyle 1 stroke:#2563eb,stroke-dasharray:5 5

Farben gibst du als Hex-Wert wie #2563eb oder als englischen Namen wie red an. Für das ganze Diagramm wählst du oben im Editor ein Theme, zum Beispiel Neutral oder Dunkel. Eigene Farben überschreiben das Theme.

Gruppen

Mit subgraph fasst du Knoten zu einem Rahmen mit Überschrift zusammen. end schließt die Gruppe.

flowchart LR
    subgraph Station
        A[Anforderung] --> B[Abnahme]
    end
    subgraph Labor
        C[Eingang] --> D[Analyse]
    end
    B --> C

Text und Sonderzeichen

  • Umlaute und Leerzeichen funktionieren direkt: A[Hämolyse prüfen].
  • Klammern, Doppelpunkte oder Schrägstriche im Text setzt du in Anführungszeichen: A["Kalium (K+): 5,8 mmol/l"].
  • Ein Anführungszeichen im Text schreibst du als #quot;.
  • Einen Zeilenumbruch im Knoten erzeugst du mit <br>: A["Erste Zeile<br>zweite Zeile"].
  • Fett und kursiv gehen mit Backticks im Text: A["`**fett** und *kursiv*`"].
  • Eine Zeile mit %% am Anfang ist ein Kommentar und erscheint nicht im Diagramm.
flowchart TD
    %% Kommentar: wird nicht angezeigt
    A["Kalium (K+): 5,8 mmol/l"] --> B["Wert prüfen<br>und melden"]
    B --> C["`**kritisch** – sofort anrufen`"]

Andere Diagrammtypen

Die erste Zeile wählt den Typ. Fertige Beispiele zu jedem Typ findest du im Editor unter Vorlage.

Ablauf zwischen Beteiligten: sequenceDiagram

    Labor-->>Station: Befund

Häufige Fehler

Bei einem Fehler zeigt der Editor unter dem Code eine rote Meldung mit der Zeilennummer. Das zuletzt funktionierende Diagramm bleibt blass stehen.

  • end als Knotentext: Kleingeschrieben beendet es eine Gruppe. Schreib Ende oder End.
  • Knoten, deren ID mit o oder x beginnt: A---oB wird zum Kreis-Ende. Setz ein Leerzeichen: A --- oB.
  • Sonderzeichen ohne Anführungszeichen: Bei A[Wert (mmol/l)] stolpert die Klammer. Richtig ist A["Wert (mmol/l)"].
  • Kommentar hinter Code: %% muss am Zeilenanfang stehen.
  • Leerzeichen in der ID: Die ID ist ein Wort ohne Leerzeichen. Den langen Text schreibst du in die Klammern.

Bedienung

  • Tab rückt im Code ein. Cmd/Strg + S speichert.
  • Speichern unter … legt eine Kopie an, auch von Diagrammen, die du nur lesen darfst.
  • Teilen gibt ein Diagramm für andere Benutzer frei, zum Lesen oder Bearbeiten. Ein öffentlicher Link zeigt es ohne Login, nur lesend.
  • SVG und PNG laden das Bild herunter, etwa für Präsentationen.
  • Ungespeicherte Änderungen zeigt ein • hinter dem Namen. Der Entwurf bleibt auch nach dem Neuladen erhalten.
  • Keine Patientendaten oder personenbezogenen Daten Dritter eintragen.
